## Contact API behavior — 25 points
- A2.2-01 (5 points). Labeled name, email and message fields collect the intended values. Half credit: Fields exist but a label or value binding is incomplete.
- A2.2-02 (8 points). A valid submission reaches a server endpoint and returns success. Half credit: The endpoint or form works separately, but the complete submission fails.
- A2.2-03 (8 points). The server rejects blank name/message and malformed email with validation feedback. Half credit: Server validation rejects some required invalid cases but misses others.
- A2.2-04 (4 points). The interface clearly distinguishes successful submission from validation or request failure. Half credit: Feedback exists but a failure or success state is unclear.
